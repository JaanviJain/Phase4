# Phase 4 — Multimodal Verifier Training

## Before you run anything, confirm:
1. Phase 1 checkpoint: copy `best_fusion_20260814_111849.pt` (F1=0.901) into `checkpoints/phase1/`.
2. Raw datasets placed in `data/raw/<dataset>/` (see folder structure below).
3. Phase 3 needs NO GPU training — only this Phase 4 code trains on GPU.

## Folder structure
```
phase4/
├── requirements.txt
├── config.yaml
├── preprocess.py
├── train.py
├── evaluate.py
├── src/
│   ├── __init__.py
│   ├── model.py
│   ├── dataset.py
│   └── trainer.py
├── checkpoints/phase1/   <- put best_fusion_20260814_111849.pt here
├── data/
│   ├── raw/{scifact,healthfc,clinifact,pubhealth}/   <- put raw dataset files here
│   └── processed/        <- auto-generated by preprocess.py
└── logs/                 <- auto-generated
```

## Run order (PowerShell)
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python preprocess.py
python train.py
python evaluate.py
```

## Known things you must verify yourself
- CliniFact label strings (`preprocess.py::preprocess_clinifact`) — the mapping is a guess.
- HealthFC / PUBHEALTH column names — auto-detected, but check the printed column list on first run.
- Filenames for each raw dataset must match exactly what's listed above, or edit `preprocess.py`.
